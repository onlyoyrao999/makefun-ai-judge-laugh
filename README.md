One joke about office life, aimed at the AI judge. It opens with a painfully true observation — the office printer only ever jams when a deadline is five minutes away — and the punchline promotes the printer to the office's most reliable colleague, the one that never misses a deadline (by making you miss yours). The program writes the 21-word joke to `/output/entry.txt`, checks it against the competition gate (1–200 characters, a single line), and reads the file back to verify it.

## Run it

```sh
python3 main.py
```
